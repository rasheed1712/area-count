# حساب المساحات

برنامج ويب لحساب:

- Net Area
- Common Area
- Gross Area
- معامل التحميل
- عدد الشقق حسب الطوابق
- تصدير النتائج إلى Excel
- طباعة النتائج PDF

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع الملفات التالية إلى المستودع:
   - index.html
   - .nojekyll
   - README.md
3. افتح:
   Settings → Pages
4. من قسم Build and deployment اختر:
   Deploy from a branch
5. اختر:
   Branch: main
   Folder: / (root)
6. اضغط Save.
7. انتظر قليلاً، ثم سيظهر رابط البرنامج.

البرنامج لا يحتاج قاعدة بيانات أو خادم، ويعمل مباشرة من المتصفح.
