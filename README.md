# حساب المساحات — نسخة قابلة للتثبيت PWA

هذه النسخة تعمل على GitHub Pages ويمكن تثبيتها على الحاسبة كتطبيق مستقل.

## ملفات الرفع
ارفع جميع الملفات والمجلدات كما هي:
- index.html
- manifest.webmanifest
- service-worker.js
- .nojekyll
- icons/

## تشغيل GitHub Pages
1. افتح Settings
2. افتح Pages
3. Source: Deploy from a branch
4. Branch: main
5. Folder: / (root)
6. اضغط Save

## تثبيت البرنامج على الحاسبة
بعد نجاح النشر:
1. افتح رابط الموقع في Google Chrome أو Microsoft Edge.
2. اضغط زر «تثبيت حساب المساحات» أسفل الصفحة.
3. أو اضغط أيقونة التثبيت الموجودة في شريط عنوان المتصفح.
4. بعد التثبيت سيظهر البرنامج في قائمة Start ويمكن تثبيته على سطح المكتب.

مهم: ميزة التثبيت تعمل بعد النشر عبر HTTPS، وGitHub Pages يوفر HTTPS تلقائياً.
